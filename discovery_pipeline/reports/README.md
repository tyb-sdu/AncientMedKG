# Public discovery reports

Reports in this directory contain only public chemical identifiers, aggregate
corpus counts, integrity fingerprints, and explicit scientific boundaries.
They must not contain document snippets, PDF paths, databases, model artifacts,
credentials, or unpublished annotations.

`intake_baseline_v1.json` records the 2026-07-31 machine intake. It is not an
approved compound ranking and it is not evidence of efficacy.
